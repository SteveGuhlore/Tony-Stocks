How it flows
EOD runs
→
Bot writes full daily note to Vault 1
Bridge writes
→
Curated markdown drops to Command Center bridge folder
Tony reads
→
Opens bridge file directly (no MCP), does deep analysis
Vault 2 updates
→
Tony updates signal-ledger.md, index.md, ticker notes
Why markdown, not JSON
Tony is a Claude agent — he reads markdown naturally. No parsing needed, no character limits from JSON wrapping, and the bridge file is also human-readable in Obsidian. You can open it and see exactly what Tony is working from.
One file per day
Named YYYY-MM-DD.md — not overwritten, so Tony can look back at previous briefs. The "Previous brief" link at the bottom lets Tony compare today vs yesterday.
What stays in Vault 1 only
Full scored symbol table (175 rows), all skip reasons, raw rotation data. Only curated signals cross the bridge — the Command Center stays clean.
No MCP in the write path
Python writes directly to the Command Center folder on disk. No Obsidian plugin, no API call, no 50-char limit. The file appears in Obsidian immediately.
