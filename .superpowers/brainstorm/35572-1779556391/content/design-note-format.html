No character limits — here's why
Notes are written by Python directly to disk (open(path, 'w')). Obsidian reads the folder as a vault — no API, no MCP plugin in the write path. Notes grow as long as they need to. The [[wikilink]] syntax means Obsidian auto-connects related notes (daily → ticker → sector) without any extra config.
