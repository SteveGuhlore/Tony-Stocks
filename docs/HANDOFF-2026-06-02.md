## Gotchas in this environment
- A GateGuard hook interrupts Write/Edit/destructive Bash asking to "present facts" — answer briefly (file, purpose, no prod data, the instruction) and retry. To silence it for a session: `ECC_GATEGUARD=off` or add `pre:edit-write:gateguard-fact-force` to `ECC_DISABLED_HOOKS`.
- A cost-tracking hook prints stale/critical cost notices — informational.
- Windows: CRLF/LF git warnings are harmless. Use PowerShell or the Bash tool.
- Don't kill all `node` processes — the Command Center terminal and MCP servers run node too.
